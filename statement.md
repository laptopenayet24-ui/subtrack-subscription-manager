# Project Statement: Subscription Management System

## Problem Statement
Managing multiple recurring SaaS, utility, and entertainment subscriptions manually leads to missed renewal dates, unexpected charges, and poor financial visibility. 

## Scope of the Project
A Python-based Command-Line Interface (CLI) application designed to securely manage, track, and analyze recurring personal subscriptions using local JSON file persistence.

## Target Users
* Individuals seeking to monitor recurring monthly and annual expenses.
* Budget-conscious users needing automated renewal warnings.

## High-Level Features
1. User profile management.
2. Complete CRUD operations (Add, View, Edit, Delete subscriptions).
3. Financial analytics (monthly/annual burn rate calculations).
4. Automated 7-day renewal warnings.
5. Persistent JSON storage with robust error handling.
